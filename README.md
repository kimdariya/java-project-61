# Brain-games
___

# Description:
Brain Games is a console-based collection of five Java-based math games designed to train logical thinking and basic arithmetic skills. Each game presents a series of three questions that must be answered correctly to win.

___

# Games:

## Even:
Objective of the game: Determine whether a random number is even.
How to play: You are shown a number, and you must answer yes if it is even, or no if it is odd.

## Calc:
Objective of the game: Calculate the result of an arithmetic expression.
How to play: You are shown an expression with two numbers and an operator (+, -, *). You must enter the correct result.

## GCD:
Objective of the game: Find the greatest common divisor of two random numbers.
How to play: You are shown two numbers and need to find their greatest common divisor.

## Progression:
Objective of the game: Find the missing number in an arithmetic progression.
How to play: You are shown a sequence of 10 numbers, where one number is replaced by ... You need to determine which number is missing.

## Prime:
Objective of the game: Determine whether a number is prime.
How to play: You are shown a number, and you must answer yes if the number is prime, or no if it is composite.

___

# How to play
After launching, you will see a menu:

Please enter the game number and press Enter.
1 - Greet
2 - Even
3 - Calc
4 - GCD
5 - Progression
6 - Prime
0 - Exit 

## Rules:

- Select a game number (1-6)

- Answer the questions

- To win, you must correctly answer 3 questions in a row.

- If you make a mistake, the game ends and you'll be asked to try again.
